## Requirements

1. Export `DefaultAccessDiscoverer` from `access/__init__.py`; implement the exact
   async protocol. Inject configured OA providers. Use passed `now`, not a hidden clock.
2. Query enabled P0 Unpaywall/OpenAlex sources for the effective accepted work.
   Preserve every consulted source, failure, timestamp, locations, policy version,
   project/work IDs. Do not invent unsupported identifier lookups when DOI is absent.
3. Every source answered: `complete`; some answered/some failed: `partial`;
   none answered: `failed`. An empty successful answer is an answer. Define and test
   the no-configured-source and no-supported-identifier cases without false `none_found`.
4. Provider failures become `sources_failed`; do not raise them or lose another
   source's eligible location. Do not swallow cancellation or process-control errors.
5. Classification: any eligible location wins `eligible_found`; without one,
   explicit restriction evidence gives `restricted`; complete empty discovery gives
   `none_found`; other cases give `unknown`. Failures alone never imply restriction.
6. Eligibility v1: work-specific records from enabled OA providers, recognized
   repositories (D-11: host_type=repository listed by Unpaywall/OpenAlex), or user
   approval for that work. Mere URL reachability, a licence, or a local copy is not enough.
   Do not trust arbitrary pre-set eligibility from an unrelated/disabled source.
7. Keep licence separate. Unknown stays unknown; do not infer redistribution rights.
   Preserve provider provenance, versions and location identity while deduplicating safely.
8. Version helpers implement `prefer_published` (published then accepted manuscript),
   `any_eligible`, `cited_version_only`. Flag `VERSION_DIFFERENCE` where versions differ.
   Do not confuse version preference with access classification. Use frozen shapes;
   put explanatory version results in owned helpers where the models lack a field.
9. Use exact wording: "No eligible copy was found in the configured sources (<list>)
   at <check time>." Do not label availability "paywalled". Keep wording in one helper.
10. Return an unsaved AccessCheck with a new check ID. Caller stores the new current
    check through AccessCheckRepo; previous checks remain superseded history.
    No direct persistence or cross-project mutation inside the discoverer.
11. No network outside injected providers; all tests offline. No new dependencies,
    printing, SystemExit, contract changes, or edits outside OWNED paths.
