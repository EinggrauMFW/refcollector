## Requirements

1. Export `DefaultIdentityResolver` from `identity/__init__.py`. Implement all three
   protocol methods exactly. Inject configured metadata providers; no hidden network client.
2. Read DOI, arXiv, ISBN, PMID conservatively. Handle DOI URLs, trailing punctuation,
   line-break artifacts, and ISBN normalization without inventing identifiers.
3. Gather identifier-linked records in Crossref, DataCite, doi.org order. Search
   Crossref, OpenAlex, Semantic Scholar. Respect configured providers and preserve failures.
   Provider failure must not discard successful evidence or become false agreement.
4. Normalize and deduplicate records, preserving provider evidence. Score every
   candidate, including forced/identifier-linked DOI results. A DOI is not acceptance.
5. Port legacy normalization, stemming, `match_score`, and `assess` thresholds unchanged.
   Compute rapidfuzz token-set ratio as a stored feature. D-10: its policy-v1 role is
   the top-two closeness gate, margin 0.05 on the combined ranking score.
6. Include DOI agreement, title similarity/distinctiveness, personal/corporate author,
   year ±1, venue, volume/issue/pages, source type, edition/version evidence. Missing
   evidence is not agreement. Provider agreement is supporting evidence only.
7. Rank deterministically, retain at most five, compare the top two. Distinctive text
   candidates need supporting fields and no close runner-up. Use
   `MULTIPLE_CLOSE_CANDIDATES` when ambiguous; do not auto-accept.
8. A valid DOI for the wrong title/author yields `needs_review` with
   `DOI_TITLE_CONFLICT`/`AUTHOR_CONFLICT`. Editions, chapters and supplements require
   a decision when they differ from the citation. Preserve all relevant reason codes.
9. Return only `accepted_auto`, `needs_review`, or `unresolved`; accepted_index points
   to the accepted candidate only for automatic acceptance. Never accept rejected metadata.
   Set the exact identity-policy version. No user or agent approval is fabricated.
10. If ordinary candidates cannot be accepted, support ISBN/Open Library, report and
    standard patterns, and OpenAlex type-aware grey-literature fallback through the
    available provider interface. Preserve literal/single-name authors and records without DOI.
11. `evaluate` scores one candidate without network or persistence. Reasons have
    plain-language explanations plus observed values in features/evidence or an owned helper.
12. `merge_metadata` is pure. Respect project locks, including locked override values,
    then identifier-linked, corroborating, parsed, and agent precedence. Do not mutate
    inputs or leak state across projects. Document the source_rank mapping you use.
13. Citation/provider text is data only. No printing, SystemExit, live test traffic,
    dependencies, contract edits, or changes outside OWNED paths.
