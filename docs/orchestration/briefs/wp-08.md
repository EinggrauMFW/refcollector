## Requirements

1. Export concrete defaults from `files/__init__.py`: `DefaultNetGuard`,
   `DefaultFileVerifier`, `DefaultRetriever`, `DefaultLocalCopyChecker`.
   Match frozen protocol methods exactly; inject collaborators and Limits as needed.
2. HTTPS only. Reject private, loopback, link-local, metadata, unspecified, multicast,
   reserved/non-public destinations, including IPv4-mapped IPv6 and mixed DNS answers.
   Parse hostnames safely; reject credentials and malformed destinations. Check every redirect.
3. Guard DNS rebinding at the actual connection boundary, not only two preflight DNS
   lookups. Existing HttpClient calls guard.check and then opens a separate connection.
   Inspect whether its frozen interface supports safe pinning/peer validation. If not,
   report an exact contract/owned-boundary change request and evidence. Do not claim
   DNS-rebinding protection or weaken this requirement. Complete independent components.
4. Use HttpClient.download for streaming into a fresh FileStore temp path. Enforce
   Limits.download_bytes (100 MiB), download_timeout_s (120 s), max_redirects (5).
   Cancellation/interruption/error removes temp data. Never commit a partial file.
5. Verify content type, `%PDF`, and full parse. Invalid file gives failed with
   FILE_VALIDATION_FAILED and stores nothing. Keep typed failures actionable.
6. Extract DOI/title evidence from first two pages; compare accepted effective metadata.
   Missing evidence is not agreement. Wrong DOI/title, supplement or wrong work gives
   `needs_review` with evidence/reasons, never verified. Do not execute PDF content.
7. Detect copy version conservatively; unknown remains unknown. Close PDF handles.
   Respect locked effective metadata/overrides; never mutate work or access classification.
8. Try eligible locations in supplied policy order. Do not download ineligible URLs.
   Only verified/needs_review files reach FileStore.commit and project grant.
   Return unsaved WorkFile with correct state, reasons, URLs, hash, bytes, location,
   and export name from the existing output helper. Test fallback and failure behavior.
9. Local copies: evaluate all five checks independently and retain failing check:
   record found, attachment present, readable, identity match, version satisfies policy.
   Only all-pass copies are usable; unknown version fails the version check.
10. Managed-store reuse requires a verified file for this work in this project plus
    project grant. Never reuse needs_review files or another project's grant. Validate
    attachment existence/readability and use user_attached origin; managed origin is
    managed_retrieved. User attachments copy into managed storage as appropriate.
11. Implement all version policies locally or through injected helpers: prefer published
    then accepted manuscript, any eligible, cited version only. A preprint under
    cited_version_only fails unless it is the cited version. No fabricated version hints.
12. Expose usable local-copy results for the pipeline to select satisfied_by_local_copy
    and skip download. LocalCopyChecker returns unsaved rows; pipeline owns transitions.
    Do not change access classification or label a local file open access. No Zotero in P0.
13. All tests offline with generated PDFs and fake HTTP/DNS/transport. No live downloads,
    network tests, binary PDF commits, dependencies, contract edits, or out-of-scope edits.
