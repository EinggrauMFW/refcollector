## Requirements

1. `DefaultExporter` implements `Exporter` exactly: `render(fmt, rows, *, selection, project)` for every P0 `ExportFormat` (`bibtex`, `csl_json`, `csv`, `json`, `unresolved`, `audit_report`) and `manifest(project, *, selection, files, counts, policy_versions)`. Unknown format -> `errors.InvalidInput`. (12.1)
2. Effective metadata of a row = `work.metadata` with `work.overrides` applied on top (overrides win). Text in force = `occurrence.text`.
3. Selections (12.1): `accepted` = identity in `ACCEPTED_IDENTITIES` and extraction not `excluded`; `reviewed` = `accepted_user` only, not excluded; `complete_audit` = every row, any state, excluded included. Apply the selection inside `render` from the rows given.
4. Bibliographic formats (BibTeX, CSL JSON): accepted rows from metadata. In `complete_audit`, rows without accepted metadata (unresolved, needs_review, excluded, ...) appear built from the citation text, clearly marked incomplete (BibTeX `@misc` with `note = {INCOMPLETE: <state>; <text>}`; CSL `note` field). (12.1)
5. BibTeX via `bibtexparser` v2 (2.1 installed): unique citation keys like v0.1 `bib_key` + `unique_keys` (`Babarit2012Numerical`, then `a/b/...` suffixes); keys shared by BibTeX and CSL JSON; corporate or single-name authors (`Person.literal`) kept whole in braces (`{World Health Organization}`) so they are not split. (AT-07)
6. CSL JSON: v0.1 `to_csl` mapping and `CSL_TYPES`; `Person.literal` -> `{"literal": ...}`; works without a DOI keep their URL and type (report/standard -> `report`/`standard`). (AT-06, AT-07)
7. CSV: one row per selected occurrence with occurrence ID, source ID, label, text, identity state, reasons, title, authors, year, venue, DOI, URL, discovery, classification, local copy, retrieval. Formula-injection neutralised: any cell starting with `=`, `+`, `-`, `@`, tab or CR gets a leading `'`. UTF-8 with BOM-free output, RFC 4180 quoting. (AT-17)
8. Full JSON: every selected row with occurrence summary, effective metadata, decision origin (principal/channel/origin, approval if any), access check (discovery, classification, sources consulted/failed, checked_at, locations) and files (sha256, state, export_name). Deterministic key order.
9. Unresolved list: one entry per row whose identity is `unresolved` or `needs_review` (and not excluded), with occurrence ID, label, reasons and text; plain text.
10. Audit report (Markdown): project name, revision, selection, policy versions, counts by every 7.3 dimension, then per-occurrence lines with identity label (9.4 wording: "Strong evidence", "Accepted by agent", "Accepted with user approval", "Needs review", "Unresolved"), reasons, decision origin, access wording. `none_found` wording exactly per 10.1: "No eligible copy was found in the configured sources (<list>) at <check time>." The word "paywalled" never appears. Excluded occurrences listed with their reason. (12.1, W-27)
11. `manifest.json`: project ID, revision, selection, policy versions, counts, and for every rendered file its name, media type, byte size and SHA-256. Deterministic, sorted keys. (12.1, W-25)
12. Export file names for PDFs: helper `export_file_name(metadata) -> "{year}_{first_author}_{short_title}.pdf"`, ASCII, filesystem-safe, short title max 6 words / 60 chars, `n.d.`-style fallback `noyear`, `anon` when no author; uniqueness helper for collisions. (10.4)
13. `DefaultDraftRenderer` implements `DraftRenderer` exactly: one `.txt` bundle with all drafts plus one `.eml` per draft (RFC 5322 via `email.message.EmailMessage`, `To:` empty, no send capability). Templates for `en` and `id`. (12.2, 11.4 tool 20)
14. Draft content (12.2, G10): built only from accepted metadata and sender fields. Neutral greeting ("Dear authors," / "Yth. Bapak/Ibu penulis,") unless `sender.honorific_style` is given. No statement about subscriptions, access rights or library access unless the sender supplied it in `purpose`. Availability wording exactly: "I could not find an eligible copy in the sources I checked." (Indonesian equivalent). Never "no legal copy exists". Recipient blank. (AT-16, AT-38)
15. `group_by_author=True`: one draft per first author (corresponding author is not known in P0; state this assumption), listing all their works; else one draft per work.
16. Renderers are pure and deterministic for the same input (no current time unless passed in through rows/project; sort stable by occurrence order).

## Tests you must add or make pass

Under `tests/unit/outputs/`, building `ExportRow`s by hand (no database):

- Selections: an excluded accepted occurrence is absent from `accepted` and present in `complete_audit` (W-16, W-27); `reviewed` contains only `accepted_user`.
- AT-06: a report/standard without DOI renders in BibTeX and CSL JSON with title, year, URL.
- AT-07: corporate author ("World Health Organization") and a single-name author survive BibTeX (braced) and CSL (`literal`); the BibTeX output parses back with `bibtexparser` and keeps the name.
- AT-17: CSV cells starting with `=`, `+`, `-`, `@` are prefixed with `'`; parse back with `csv` and compare.
- `complete_audit` marks unresolved rows as incomplete in BibTeX and CSL.
- Unique keys: two works with the same author/year/title word get distinct keys, the same in BibTeX and CSL.
- Audit report: contains every occurrence in `complete_audit`, the 10.1 `none_found` sentence with sources and time, and never the word "paywalled" (case-insensitive) for any classification.
- Manifest: SHA-256 and byte size match each `RenderedFile.data`; revision and selection present; output stable across two calls.
- Drafts: `.eml` `To` header empty (AT-16); text contains "I could not find an eligible copy in the sources I checked." and never "no legal copy" (AT-38); no "Dear Dr."; no subscription claim unless in `purpose`; Indonesian template; `group_by_author` grouping; honorific style used when given.
- `export_file_name` cases: normal, no year, no author, non-ASCII names, long title, collisions.
- Unknown format -> `InvalidInput`.
