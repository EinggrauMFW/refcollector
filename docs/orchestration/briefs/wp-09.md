## Goal

Implement `RefCollectorService` (contracts/api.py): one method per P0 tool plus the two CLI-only
calls. Services validate, check scopes, paths and network mode, enforce idempotency and revisions,
record provenance and audit events, and **enqueue** jobs. They never run pipeline steps (spec 5).

## Design

- `RefCollectorServiceImpl(settings, store, queue, *, extractor, identity_factory, local_copies, clock=utcnow)` in `services/service.py`. `identity_factory(snapshot) -> IdentityResolver` (lets `resolve_citation` and `set_doi` build a provider client for the current settings; tests pass a fake). Keep it injectable; WP-10 builds the real one in `bootstrap.open_app`.
- Every public method: check scope (`ctx.scopes`; `start_job` per stage via `STAGE_SCOPES`; missing -> `NotAuthorized`), run, fill `meta={request_id, project_revision}`.
- Mutations: one `store.transaction(immediate=True)` (D-26); project revision +1 per committed mutation (11.3); audit event with `Provenance(principal=ctx.principal, channel=ctx.channel, origin=ctx.origin)`.
- Idempotency (11.3): scope (principal, project_id or "", tool, key); fingerprint = sha256 of the canonical JSON of the request without `idempotency_key`; same fingerprint -> return stored result unchanged (no second change, AT-12a); different -> `IdempotencyConflict`; TTL `limits.idempotency_ttl_s`.
- Revisions: `expected_revision` mismatch -> `RevisionConflict` with current revisions, nothing applied; merge checks all (AT-39, `check_revisions`).
- IDs are project-scoped: another project's ID -> `NotFound` (11.2).

## Requirements by tool

1. `get_capabilities`: P0 values only (source_types pdf/text, stages, adapters {builtin: true, grobid: false, ocr: false}, providers with enabled/configured, local_copies managed/attached, export formats, approval_surfaces ["cli_tty"], limits, scopes_granted, config {email_set, keys presence from `config.secrets_present()` — tolerate a missing keyring backend}).
2. Projects: `create_project` (defaults per D-12), `list_projects` (counts), `get_project` (counts by identity/access/retrieval, recent jobs and artifacts).
3. `import_source`: local path must resolve (after `Path.resolve(strict=True)`, symlinks followed) inside an allow-listed folder (`settings.allow_folders`), else `PathNotAllowed`; missing file -> `NotFound`; detect PDF/text from content; preflight via the extractor (its errors propagate); store bytes via `store.files` + grant; same sha256 in project -> existing `source_id` with `reused: true` (W-02); text input limit 1 MB. P1 types already fail in the DTO (D-19).
4. `list_sources`, `get_source`; `set_source_sections` with `expected_source_revision`, replaces sections (manual), `requires_reextract: true`.
5. `start_job`: preconditions (extract needs `source_ids`; resolve needs extracted occurrences; discover_access needs accepted identities) -> `PrerequisiteNotMet`; network stages in offline mode -> `NetworkModeDenied`; network stages need `settings.email` -> `ConfigMissingEmail`; build `ConfigSnapshot` from current settings + project; create the job through `queue.create_job` with stages as `StepType`; `steps_planned` = number of subjects of the first stage (D-22); `next_poll_after_ms`.
6. `get_job`: stage counts from `queue.stage_counts`, warnings, `results` (`source_ids`, `occurrence_count` from job links, `changed_filter={"job_id": ...}`, `artifact_ids`), `next_poll_after_ms` while not terminal.
7. `control_job`: `queue.request`; invalid -> `InvalidState`; idempotent.
8. `list_references` (filters incl. `job_id`, `reason`, `query`, `sort`, `fields` projection), cursors per D-13 (opaque, signed or encoded; expired after 24 h -> `InvalidInput`), default 25, max 100; `get_reference` with requested sections (candidates, evidence, access history current first, local copies, files, history = audit events + decisions).
9. `add_reference`: new occurrence, `extraction=corrected`, ordered after `after_occurrence_id` (midpoint `order`).
10. `update_reference` change types (11.4 tool 15): `edit_text` (sets `edited_text`, keeps raw text, principle 2), `split` (new occurrences linked by `predecessor_ids`, original excluded or superseded; only new ones need re-resolution, AT-03), `merge` (all revisions checked), `exclude`/`restore`, `select_candidate` (identity `accepted_agent`, Decision with origin from ctx, AT-13/W-17), `reject_candidate` (candidate `rejected=True`, never re-accepted), `set_doi` (evaluated through the identity policy, 9.2; accept only when no conflict, else `needs_review` with reasons), `set_fields` (only `SETTABLE_FIELDS`, stored as ProjectWork overrides), `set_field_locks`, `mark_unresolved`. Any change to text, candidate set or accepted fields after an approval makes it stale: identity -> `needs_review` with `APPROVAL_STALE`, both events audited (7.4, D-20, AT-34, W-19). Locks and rejections are per project (AT-42/43).
11. `review_decision` (CLI only): require `ctx.channel == cli_tty_review and ctx.tty`, else `NotAuthorized`; accept -> `accepted_user` with `Approval(occurrence_revision = the new revision)` (W-18); reject -> candidate rejected.
12. `resolve_citation`: no project, stores nothing but provider cache; `decision_hint` strong/needs_review/unresolved.
13. `attach_file`: path allow-list as above; copy into store (`user_attached`), run `DefaultLocalCopyChecker.evaluate(...)` with the attached path and `version_hint`, store the LocalCopy, set occurrence `local_copy`; when all five checks pass set retrieval `satisfied_by_local_copy` (AT-26, W-22); access classification never changes.
14. `download_files`: scope `files:download` must be granted (MCP default lacks it, 11.2) and enabled for the project or globally (`project.download_enabled` / `settings.download_enabled_global`) else `NotAuthorized`; network mode must be `retrieval` else `NetworkModeDenied`; identities accepted and discovery run else `PrerequisiteNotMet`; enqueue a job with stage `retrieve` and the budget in options.
15. `create_export`: `project_revision` != current -> `RevisionNotCurrent` with the current value (AT-40, W-26); enqueue an `export` job with formats and selection.
16. `draft_requests`: each occurrence's classification must be `none_found`, `restricted` or `unknown` else `PrerequisiteNotMet`; enqueue a `draft` job.
17. `list_artifacts`, `read_artifact` (descriptor with `file://` path inside RC_HOME; text read in bounded chunks <= 64 KB with `offset`/`length` and `eof`, W-28; binary -> descriptor only).
18. `update_project_settings` (CLI only, D-23): network mode, download_enabled, version policy; audited.
19. Untrusted text (PDF, provider data) is stored as data; nothing in it changes permissions or decisions (AT-14).
