## Requirements

1. Commands (14.1): `project create|list|show`, `import PATH|--text`, `sections SOURCE_ID --pages A-B[,C-D]`, `run --stages extract,resolve,discover_access [--source ID...|--occurrence ID...] [--wait]`, `jobs [JOB_ID] [--pause|--resume|--cancel|--retry-failed]`, `list` (filters matching `list_references`), `show OCCURRENCE_ID`, `review`, `edit`, `split`, `merge`, `add`, `exclude` (and `--restore`), `attach OCCURRENCE_ID PATH [--version]`, `download [--occurrence ID...]`, `export --revision N --format ... --selection ... [--audit]` (`--audit` = `complete_audit` + audit report), `requests` (drafts), `serve [mcp|web]`, `config` (`show`, `set email X`, `allow-folder PATH`, `set-key NAME` reading the secret from a hidden prompt, `network MODE --project ID`, `downloads on|off --project ID`).
2. A global `--project NAME_OR_ID` option (or `RC_PROJECT` env); name resolves through `list_projects`.
3. Every command builds `CallContext(principal=getpass.getuser(), channel=Channel.CLI, scopes=frozenset(Scope), request_id=new_id("request"))`; non-interactive commands are `origin=agent` (7.4). Mutating commands generate an idempotency key (uuid4 hex) unless `--idempotency-key` is given.
4. Edits take the occurrence revision automatically from `get_reference` unless `--expected-revision` is given; on `REVISION_CONFLICT` print the current revisions and exit non-zero.
5. `review` (TTY approval surface): refuse unless `sys.stdin.isatty() and sys.stdout.isatty()` (print why, exit 2). Context: `Channel.CLI_TTY_REVIEW`, `tty=True`. Walk `needs_review` occurrences (then optionally `accepted_auto/agent` with `--all`): show the citation text, each candidate with metadata and reason sentences, then read **one keypress per decision**: `a` accept top candidate, `1-5` choose candidate, `r` reject, `d` set DOI, `e` edit text, `s` split, `m` merge with next, `x` exclude, `n` add after, `u` mark unresolved, `k` skip, `q` quit. Accept/choose -> `review_decision(action="accept")` (yields `accepted_user`, W-18); other actions use `update_reference`/`add_reference`. Read keys through an injectable `read_key` function (msvcrt on Windows, termios/tty on POSIX) so tests can drive it.
6. `--json` flag on read commands prints the DTO JSON; default output is a compact table/text (`render.py`). Untrusted text is printed as plain text; strip ANSI/control characters from document and provider text before printing (13).
7. Error handling: catch `RcError` at the command boundary, print `code: message` and the recovery hint to stderr, exit 1 (2 for usage errors). Only `cli/main.py` entry point raises `SystemExit` (6.6).
8. App creation: a module-level `get_app()` dependency that calls `bootstrap.open_app(load_settings())` once and `start_executor()` (6.1), overridable in tests (e.g. `set_app_factory(...)`). `run --wait` polls `get_job` until terminal, printing stage counts. `serve mcp` calls `refcollector.mcp.server.run_stdio(settings)` (import lazily; WP-11 builds it). `serve` (no arg) runs a long-lived executor until Ctrl-C. `serve web` -> `FEATURE_NOT_AVAILABLE` (D-05).
9. Provenance fields can never be set from CLI options.
